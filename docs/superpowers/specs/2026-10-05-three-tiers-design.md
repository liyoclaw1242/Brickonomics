# 積木城市：初／中／高三階課程與事件元件庫 — 設計規格

- 日期：2026-10-05
- 狀態：使用者已確認（三段討論），授權「寫規格後直接進實作」
- 前情：Plan 1–5 已合併；使用者測試加了「簡單版／完整版」兩條路線；b-3 有龍捲風、c-1/c-2 有閃電。

## 1. 目標

把課程改成像「小學／國中／高中數學」的三階：每一階都教股票、債券、基金、ETF 四種商品，但深度不同。
- **初階：是什麼**（現在的簡單版）
- **中階：怎麼比**
- **高階：怎麼組合、怎麼控風險**

使用者的決定：
1. 高階只用現有四種商品，**不放期貨、選擇權、融資融券**。對沖用「反向 ETF」與「股債互補」講；當沖只講成本、風險、為什麼多數人賠。
2. 三門**獨立**的課，開場自由選；只**建議**順序，不鎖。每門課最後一頁推薦下一階。
3. 中階、高階的第一步是**前一階口訣複習**，之後只教新東西（每階約 15～20 步）。
4. 金融事件一律用**天氣／自然現象**的共用元件呈現（見 §4）。
5. 人物測試一律用 **Fable agent**，每階一個人物（見 §6）。
6. 這次**不放** REITs、匯率、外幣債、年齡法則。

## 3. 架構

- **步驟池**：所有步驟仍以 id 唯一識別（現有 LEVELS 內的步驟 + 新步驟）。步驟資料定義不變（title/line/more/marks/bigNumber/focus/callouts/scene/controls/until）。
- **課程**（純資料，`src/tour/courses.ts`）：`Course = { id: 'beginner'|'intermediate'|'advanced'; title; chapters: { id; icon; name; stepIds: string[] }[] }`。取代 `ROUTES`。測試：每個 id 存在、每門課四章順序正確、課與課之間不重複步驟（口訣複習步各自獨立）。
- **位置**：`Position = { course, index }`（課內扁平索引），存檔另存 `stepId`。導航、進度、時間軸、步數計數、until 閘門全部以「目前課程」為單位。
- **URL**：`?course=beginner|intermediate|advanced&step=<stepId>`。舊網址 `?level=&step=`、`?route=` 轉換到對應課程（simple→beginner、full→依步驟所在課程），e2e 與截圖腳本改用新參數。
- **存檔遷移**：舊存檔有 stepId → 找出含該步的課程；route simple → 初階；沒有 id 的舊位置照現有遷移規則找回步驟再找課程。
- **進度**：`completed` 與「完成」狀態改成**每門課分開記**；上完任一門課就解鎖自由玩。
- **開場卡**：三個大按鈕（初階／中階／高階＋一句白話＋步數），只有第一次來顯示；工具列有「換階」選單。尚未完成的課（Plan 6 時的高階）不顯示。
- **時間軸**：顯示目前課程的章（含序章／開頭／結尾）。
- **文字版**：可選階，照課程章節列出。

## 4. 事件元件庫（`src/scene/events/`）

原則：**一種金融事件只對應一種自然現象**，全程不換（和文字的一詞一義相同）。

| 金融事件 | 現象 | 畫面要點 |
|---|---|---|
| 經濟衰退、金融風暴 | 🌪 龍捲風（已有） | 掃過才受損，弱的裂開 |
| 單一公司出事 | ⚡ 閃電（已有） | 只劈中持有該公司的方塊 |
| 股市崩盤、最大跌幅 | 🌋 地震＋地裂 | 地面裂坑，坑深＝最多少掉多少 |
| 升息 | ❄️ 寒流 | 舊借據結霜變便宜；長板子結冰更厚 |
| 通膨 | ☀️ 熱浪 | 金幣慢慢融化變小 |
| 泡沫、太貴 | 🫧 泡泡 | 大樓被泡泡包住浮起，最後破掉 |
| 長期成長、複利 | 🌤 晴天＋大樹 | 塔像樹慢慢長高 |
| 劇烈來回震盪 | 🌊 大浪 | 浪一上一下，槓桿塔每次被打矮一截 |

統一規則：
- 步驟資料以 `scene.event = { kind, targets?, params? }` 叫用；舞台不再各自內嵌天氣邏輯（龍捲風、閃電在 Plan 6 搬進來，外觀與時序不變）。
- 鏡頭停下後才發生、一次只變一件事；打擊只一次、不連續閃爍（≤ 1 次閃光）；`prefers-reduced-motion` 直接顯示靜態結果；低畫質簡化；顏色來自主題；只在動畫期間連續渲染。
- 每個事件的時間軸是純函式（`src/scene/events/*.ts`），測試「結束畫面＝最終狀態」。
- 新事件先單獨截圖驗收（黃昏、白天、手機、低畫質、減少動態）再放進課程。

## 5. 不變的規則

寫作規則（ASD-STE100 中文版，§Plan 5 規格 2.1）、3b1b 教法（2.2）、數字由資料計算、示意／假設／資料待更新標示（自動推導）、不談稅、籃子方塊數嚴格依權重、一種材質一個 InstancedMesh、Html 等第一幀、TypeScript strict 無 any、字串只在 strings.ts／課程內容只在課程資料檔。
