## 2.1 寫作規則（參考 ASD-STE100 簡化技術英文，改寫成中文版）

使用者指定參考 ASD-STE100。比喻是本教學的核心，所以保留；改成「一個比喻只對應一個概念」。

1. **一詞一義、一義一詞**：同一個概念全程只用同一個詞，術語表放在 `src/tour/glossary.ts`（純），測試禁止使用同義詞。
   - 大樓＝公司；方塊＝一小份公司（股票）；金幣＝付給你的錢。股票、基金、ETF 一律叫「配息」；債券叫「利息」。
   - 內扣費用（不寫管理費、費用率）；漲／跌（不寫上升、下滑、走高、走低）；怪手＝基金經理人；藍圖＝指數。
   - 禁用：股息、股利、派息、分紅、管理費、費用率、上升、上揚、走高、下滑、走低、下挫。專有名稱「高股息」例外。
2. **一句只講一件事**：句子用「。」分開；一句話（`line`）最多兩句，每句不超過 16 字。
3. **操作句先寫動作**：要使用者操作的步驟（有 `until`），`line` 的第一個字必須是動作詞：拖、點、切、按、選、看。
4. **定義句固定句型**：「A＝B」。
5. **主動語態、現在式**：不用「被」字句。
6. **多說一點也要短**：每句不超過 25 字，最多 4 句；句子之間不用連接長句（因為、所以、但是放在句首）。
7. **警告先講結論**：先寫會發生什麼，再寫原因（例如「塔變矮。因為發的是本金。」）。

## 2.2 3Blue1Brown 風格的教法

使用者指定參考 3Blue1Brown（3b1b）。保留黃昏配色，借用它的教法：

1. **顏色連結**：一句話裡的關鍵詞，用它所指物體的顏色顯示（例如「台積電」用台積電那層方塊的藍色、「配息」用金幣的金色）。標註與大數字的色條也用同一個顏色。語法：`**台積電|2330**`，`|` 後面是顏色鍵（持股 id、產業 id，或 `coin`、`loss`）。
2. **先看再命名**：換步驟時先移動鏡頭，鏡頭停下後再淡入標題和一句話，關鍵詞逐一出現（每段間隔 80ms）。
3. **一次只變一件事**：順序是鏡頭、焦點色調、文字。色調在鏡頭停下後才轉換，並用約 400ms 漸變，不要瞬間切換。
4. **數字會長出來**：大數字從 0 數到目標值（約 600ms）。
5. **先具體、後抽象**：每章第一步用一個具體物體（一棟樓、一顆方塊），之後才講一般規則。現有課程順序已經符合。
6. 開啟 `prefers-reduced-motion` 時，所有動畫直接顯示最終狀態。

## 3. 架構

- `src/scene/theme.ts`（純）：`ThemeId = 'dusk' | 'day'`；`THEMES[id]` 含天空／霧／燈光組（主光、補光、環境光顏色與強度）／地面／海／島／櫃台／廣場／土壤／標註色，以及方塊的 `muted(hex)`、`vivid(hex)` 轉換參數。
- `src/store/theme.ts`：zustand，`theme`、`toggleTheme()`、`labels`（標註開關）、`legend`（圖例開關）；localStorage 保存。`<html data-theme>` 同步，CSS 變數分兩組。
- `src/scene/Lighting.tsx`：依主題設定燈光、天空、霧。
- `src/scene/layout/tone.ts`（純）：`groupTone({ group, focus, picked, explode }) → 'vivid' | 'muted'`；`toneColor(hex, tone, theme)`。
- `src/scene/Callout.tsx`：錨點＋引線＋標題／副標＋可選標示圖示；`NameLabel.tsx`：淡色名稱字。
- `src/ui/layoutModel.ts`（純）：依視窗大小回傳面板／工具列／時間軸的佔用邊距與 `mobile`；`ViewFraming` 讀它；CSS 斷點單一來源。
- 面板拆分：`StepHeader`、`OneLine`（`parseEmphasis` 純函式）、`BigNumberCard`、`MoreSection`、`StepControls`、`StepNav`；`Toolbar`；`ChapterTimeline`（`chapterStates` 純函式）；`MarkIcon`。
- 課程資料：`Step` 新增 `title`、`line`、`mark?: 'illustrative' | 'assumption'`、`bigNumber?: (c) => BigNumber`、`focus?: { holdings?: string[] }`、`callouts?: CalloutSpec[]`；原 `text` 改名 `more`。數字一律由 `TextContext` 即時計算。
